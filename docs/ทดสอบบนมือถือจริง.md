# ทดสอบบนเครื่องจริง — Android และ iPhone

รอบนี้ตรวจหลังปรับหน้าจอหลายจุด (8 ต.ค. 2569) ใช้เวลาประมาณ 20–25 นาทีต่อเครื่อง

## เปิดระบบบนมือถือ

เครื่องคอมที่รันระบบกับมือถือต้องอยู่วง Wi-Fi เดียวกัน แล้วเปิด

- **ในบ้าน/ออฟฟิศเดียวกัน** → `http://192.168.1.147:3001`
- **ผ่าน Radmin VPN** → `http://26.224.66.120:3001`

ถ้าจะทดสอบ **ติดตั้งเป็นแอป (PWA) และการแจ้งเตือน** ต้องเปิดแบบ https เท่านั้น
(iPhone ไม่ยอมติดตั้งจากลิงก์ http) — บนคอมสั่ง `npm run dev:https` แล้วเปิด
`https://26.224.66.120:3000` บนมือถือ กด "ไว้ใจ" ใบรับรองตอนเตือนครั้งแรก

เปลี่ยนบทบาทที่จะทดสอบ: หน้าแรก → เมนูขวาบน → ออกจากระบบ → เลือกบทบาทใหม่

## ตรวจทุกหน้าที่เปิด (ทุกบทบาท)

- [ ] ไม่มีแถบเลื่อนแนวนอน — ลองปัดซ้าย-ขวา หน้าต้องไม่ขยับ
- [ ] ตัวหนังสือไม่ถูกตัดหรือซ้อนกัน
- [ ] ปุ่มทุกปุ่มกดติดด้วยนิ้วโป้ง ไม่ต้องซูม
- [ ] แถบเมนูล่างไม่ทับเนื้อหา และปุ่มลอยไม่ทับแถบเมนู
- [ ] กล่องเด้ง (ยืนยัน/ฟอร์ม) ปิดด้วยปุ่มกากบาทได้ และเลื่อนดูเนื้อหาข้างในได้
- [ ] หมุนจอเป็นแนวนอนแล้วยังใช้งานได้

## เฉพาะ iPhone

- [ ] Safari — แถบที่อยู่เว็บไม่บังปุ่มล่าง (เลื่อนขึ้น-ลงแล้วดู)
- [ ] ช่องกรอกตัวเลขขึ้นแป้นตัวเลข ไม่ใช่แป้นตัวอักษร
- [ ] แตะช่องกรอกแล้วหน้าไม่ซูมเข้าเอง
- [ ] ขอบล่าง (แถบ Home) ไม่ทับปุ่ม
- [ ] ติดตั้งเป็นแอปจาก Safari → แชร์ → เพิ่มที่หน้าจอโฮม แล้วเปิดใช้งานได้

## เฉพาะ Android

- [ ] Chrome — ปุ่มย้อนกลับของเครื่องทำงานถูกต้อง ไม่หลุดออกจากระบบ
- [ ] ติดตั้งเป็นแอปจากหน้า `/install` แล้วเปิดจากไอคอนได้
- [ ] การแจ้งเตือนเด้งจริง (ต้องเปิดผ่าน https)
- [ ] ปิดเน็ตแล้วเปิดแอป ต้องขึ้นหน้า "ออฟไลน์" ไม่ใช่หน้าขาว
