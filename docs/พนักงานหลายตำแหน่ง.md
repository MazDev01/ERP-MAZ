# บทบาท "พนักงาน" มีหลายตำแหน่ง — สิ่งที่ผมเข้าใจและกำลังทำ

เขียนไว้ให้เจ้าของอ่านก่อน ถ้าเข้าใจผิดตรงไหนบอกได้ แก้ก่อนทำต่อ · 29 ก.ย. 2569

## โจทย์ที่ได้รับ
> "บทบาทพนักงานมีหลายตำแหน่ง … สลับคนที่ล็อกอินได้ บทบาทพนักงานหรือพนักงาน มีหลายตำแหน่ง
> เช่น dev sa bd ตัดต่อ ให้สามารถแสดงในหน้าตามตำแหน่งได้"

## ปัญหาของระบบตอนนี้
บทบาท **พนักงาน** ถูกผูกกับคนเดียวตายตัว คือ **กมลชนก พูนสุข (E05) ตำแหน่ง Website**
เข้าระบบเป็นพนักงานทีไรก็เป็นคนนี้เสมอ ทั้งที่จริง ๆ พนักงานมีหลายตำแหน่ง
(SA · Dev · Graphic · Content · Website · Media planner · BD) และงานของแต่ละตำแหน่งไม่เหมือนกัน

## สิ่งที่ผมเข้าใจว่าต้องได้
1. **เลือกได้ว่าเข้าเป็นใคร** ตอนเข้าสู่ระบบ (และสลับทีหลังได้จากเมนูผู้ใช้)
   รายชื่อมาจากทะเบียนฝ่ายบุคคล เฉพาะคนที่ยังทำงานอยู่
   และไม่ใช่คนที่มีบทบาทของตัวเองอยู่แล้ว (ฝ่ายขาย · PM · บัญชี · บุคคล · GM · ก่อนการขาย)
2. **ทุกหน้าเป็นของคนที่เลือก** ไม่ใช่ของกมลชนกค้างอยู่
   - ชื่อ ตำแหน่ง แผนก หัวหน้า วันเริ่มงาน ประเภทพนักงาน อีเมล เบอร์
   - งานที่ได้รับ / ตารางงาน = เฉพาะงานที่ PM มอบให้คนนั้น
3. **เมนูและเนื้อหาขึ้นตามตำแหน่ง** เช่น Media planner เห็นงานสายโฆษณา ส่วน Dev ไม่เห็น

## วิธีที่ทำ
- เก็บแค่ **รหัสพนักงาน** ของคนที่ใช้อยู่ (`maz-erp.staff-emp.v1`)
  ข้อมูลอื่นอ่านจากทะเบียนฝ่ายบุคคลเสมอ — ฝ่ายบุคคลแก้ตำแหน่งเมื่อไร ระบบเปลี่ยนตามทันที
  ไม่ใช่คัดลอกค่าไปเก็บไว้แล้วค้างเป็นของเก่า
- โปรไฟล์ที่ทุกหน้าอ่านร่วมกัน (`profile-data`) ถ้าบทบาทเป็นพนักงาน
  จะประกอบขึ้นจากคนที่เลือก แทนค่าตายตัวเดิม
- หน้าที่กรองงานด้วย "รหัสพนักงานของฉัน" อยู่แล้ว (งานที่ได้รับ ฯลฯ) จึงเปลี่ยนตามเองทันที

## ข้อจำกัดที่ยังไม่แก้ในรอบนี้ (ต้องบอกไว้ก่อน)
- **เวลาทำงาน ใบลา โอที ใบเบิก สลิป** ยังเก็บ "ตามบทบาท" ไม่ใช่ "ตามคน"
  สลับคนแล้วข้อมูลชุดนี้ยังเป็นก้อนเดียวกันของบทบาทพนักงาน
  ถ้าต้องการให้แยกตามคนจริง ๆ ต้องรื้อที่เก็บทั้งหมด (งานใหญ่กว่า) — สั่งได้ว่าจะเอาไหม
- ยังไม่มีหลังบ้าน การเลือกคนจึงเป็นตัวเลือกในเครื่อง ไม่ใช่การล็อกอินจริง

## ที่ยังค้างจากงานก่อนหน้า

- แดชบอร์ดมือถือของทุกบทบาท (ไฟล์ต้นแบบ dashboard / pm / acc / hr)
